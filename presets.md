# Squelch: Presets

The factory names are declared in `Source/Presets.h`. The named rows are fixed normalized values in `squelch::presets::rows`; they are not regenerated at run time. Default is the parameter-layout baseline.

Presets store the columns declared by `squelch::presets::columns`. MIX is excluded as a session-level output control.
